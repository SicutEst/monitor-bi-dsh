# BI 需求规格模板

> 复制此模板,填好内容后发给 AI 助手,说"做 Monitor BI"即可自动生成看板。
> 不确定的地方可以留空或写"由你决定",AI 会自动补全。

---

## 报表名称: (必填,如"供应商交货准时率分析")

## 数据需求

- **数据源**: (必填,从以下选一个)
  - 采购 → 采购订单/到货/供应商发票等
  - 销售 → 客户订单/报价/发票/交货等
  - 库存 → 库存余额/库存事务/组件等
  - 制造 → 制造订单/报工/工序等
  - 财务会计 → 科目余额/收入/应收应付等
  - 公共档案 → 客户/供应商/组件/公司等

- **时间维度**: (选填,默认"本年")
  - 如: 交货日期(按月) / 订单日期(按日) / 发票日期(按季度)

- **分析维度**: (必填,想按什么分组看)
  - 如: 供应商 / 客户 / 产品 / 仓库 / 状态 / 月度

- **指标**: (必填,想看什么数字)
  - 如: 采购金额(求和) / 订单数量(计数) / 准时率(百分比) / 库存余额(求和)
  - 如需计算: 说明公式,如"准时率 = 准时行数/总行数×100%"

## 展示要求

- **类型**: (选一个)
  - 趋势图 → 折线/柱状,看时间变化
  - 排行表 → 表格,按某个指标从大到小
  - 穿透表 → 汇总表+明细表,点击汇总看明细
  - 饼图 → 占比,看构成
  - 驾驶舱 → 多组件组合(卡片+图表+表格)

- **排序**: (选填,默认按第一个指标倒序)
  - 如: 按金额从大到小 / 按时间正序

- **筛选**: (选填)
  - 如: 时间(本年/去年/近12月) / 供应商(多选) / 状态(单选)

- **标注规则**: (选填)
  - 如: 准时率<60%红色, 60-80%黄色, >=80%绿色
  - 如: 逾期>30天显示红色箭头

- **页签**: (选填,如果有多个视图)
  - 如: 页1=供应商→产品排行, 页2=产品→供应商排行(两个视图独立筛选)

## 其他

- **是否需要实时数据**: (默认否,每天更新;如果需要5分钟级,填"是")
- **备注**: (任何补充说明)

## 示例(已填好的spec)

## 报表名称: 采购金额排行分析

## 数据需求
- 数据源: 采购
- 时间维度: 订单日期(按月)
- 分析维度: 供应商、产品
- 指标: 采购金额(求和)、采购数量(求和)

## 展示要求
- 类型: 穿透表(两个页签)
- 页签1: 供应商→产品排行(点供应商看产品)
- 页签2: 产品→供应商排行(点产品看供应商)
- 排序: 都按金额从大到小
- 筛选: 时间(本年/去年/本月/近12月)
- 两个页签的筛选互不联动
